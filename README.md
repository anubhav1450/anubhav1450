## Featured projects

### [Agent Trust Lab](https://github.com/anubhav1450/agent-trust-lab) — authorization and observability for AI workflows

A Python/FastAPI engineering experiment that asks: *what was an AI agent allowed to do, what happened, and what changed the outcome?*

- Built capability-based authorization with signed, scope- and amount-limited delegation tokens, enforced by a Payment API rather than trusting agent output.
- Added hash-chained execution logs, sandboxed replay, and controlled context interventions to investigate decisions.
- Integrated an optional real LLM behind validated output and recorded responses for reproducible requests; covered the workflow with automated tests.

**[Live interactive demo](https://agent-trust-lab.vercel.app) · [Code & technical walkthrough](https://github.com/anubhav1450/agent-trust-lab)**

### [Real-Time Collaborative Editor](https://github.com/anubhav1450/real-time-editor) — multi-user editing with CRDTs

A collaborative code editor built with **React, Monaco Editor, Yjs, Socket.IO, and Node.js**.

- Implemented room-based live collaboration with shared editing, presence, remote cursors, and synchronized language selection.
- Used Yjs CRDT synchronization so concurrent edits can merge without a central edit lock.
- Wrote a Playwright multi-user test exercising **20 simultaneous browser sessions**; containerized the application with Docker and deployed its frontend and backend separately.

**[Live demo](https://real-time-editor-eight.vercel.app) · [Code & setup](https://github.com/anubhav1450/real-time-editor)**

> The editor's backend runs on a free hosting tier and may need a moment to wake up on the first visit.
